# Wizard Arena

A small 2D side-scrolling wizard combat prototype, built in Unity 6 (6000.3.7f1). Clear three
arenas of enemies to reach the exit portal, or die trying -- then Retry, Continue, or start the
whole run over.

## How to play

- **Move**: Left/Right arrow keys
- **Jump**: Space
- **Cast**: Z or Enter
- **Pause**: Esc

Fight through three stages of growing difficulty (bats, then faster bats and ground enemies,
then a final gauntlet). Clear every enemy in a stage to open its exit portal, then walk into it
to move on. Health potions occasionally drop from enemies, or sit on the floor waiting to be
picked up. Losing all your HP ends the run (Retry restarts the current stage); clearing the
last stage is a Victory (Play Again restarts the whole run from stage 1).

## Running it in the editor

Open the project in Unity 6000.3.7f1 (Unity Hub will offer to install it if missing) and press
Play from `Assets/Scenes/MainMenu.unity` (or `WizardMovement.unity` to jump straight into stage
1). Both scenes are generated by editor code -- see `ARCHITECTURE.md` before hand-editing
anything under `Assets/Scenes/`.

## Running the tests

`Tools/unity/unity.sh` is a batch-mode wrapper around the Unity Editor for both humans and
agents; it needs no open Editor instance.

```
Tools/unity/unity.sh test            # EditMode, then PlayMode
Tools/unity/unity.sh test-editmode
Tools/unity/unity.sh test-playmode
Tools/unity/unity.sh compile         # just check for compile errors
```

Results go to `Logs/test-results-<platform>.xml` (JUnit-style NUnit XML); logs go to
`Logs/unity-*.log`. Set `UNITY_PATH` to override the Unity binary it looks for
(`/Applications/Unity/Hub/Editor/6000.3.7f1/Unity.app/Contents/MacOS/Unity` by default).

## Building

```
Tools/unity/unity.sh rebuild-scene   # regenerate the scenes after changing a builder
Tools/unity/unity.sh build-macos     # -> Builds/macOS/WizardArena.app (git-ignored)
```

The macOS build uses the Mono scripting backend, not IL2CPP (that module is not installed on
this machine -- see the "Known gaps" note in `ARCHITECTURE.md` if you install it and want to
switch back). Double-click `Builds/macOS/WizardArena.app` to play the built game.
